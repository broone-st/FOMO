# FOMO · 错过恐惧症

一个轻量的 A 股桌面看盘小组件：**纯 Python 标准库实现（ctypes 原生 Win32 窗口），零第三方依赖**，任意 Python 3.8+ 直接运行。白色 / 浅灰默认配色、另带**背景透明主题**、小字体、迷你置顶窗、**拖边框自由缩放**、**右键滑轨调外观**、**涨跌幅两种显示模式**、交易时段秒级刷新、全局快捷键一键隐藏。

一键下载：https://github.com/broone-st/FOMO/releases/tag/v1.0.0

> 名称含义：**FOMO = Fear of Missing Out**（"错失恐惧"）—— 侧身一瞥就能看清自选股，不用把行情软件开得满屏。

## 快速启动

> ⚠️ **这一版不含任何数据源**，必须先补 `provider.py` 才有数据 —— 见下一节。

1. 把整个文件夹（连同其中的 `给AI的提示词.md`）交给 AI，说「按这份说明把数据源补上」，
     
   AI 会新建 `provider.py`；
2. 双击 `启动FOMO.bat`（唯一推荐方式，无黑窗）。

> 本目录自带 Python 运行时（`python\` 子文件夹），**目标电脑无需安装 Python**。
>   
> 启动脚本优先使用内置运行时；只有在没有内置运行时的情况下才回退到系统 Python，
>   
> 并且会**跳过微软商店的假 Python**（`WindowsApps\python.exe` 只是商店重定向器，执行它不会有任何反应）。
>   
> 注意：拷贝时务必**整个文件夹一起拷**，只拷 `启动FOMO.bat` 是无法运行的。

首次运行会在程序目录生成 `watch_config.json`，之后所有设置都改这个文件，**保存后约 3 秒内自动生效**，无需重启。

## 数据源：`provider.py`（本版不含任何源）

程序本体**只负责画界面与显示**：没有内置接口、没有请求逻辑、没有数据解析代码。
  
所有数值都来自同目录的 `provider.py`，它由使用者自行提供：

```python
SOURCE_NAME = "你的源名字"           # 可选，显示在状态栏右端

def fetch(codes, options):           # codes: ["sh000001", ...]  options: dict
    return {code: quote}             # quote 字段：code/name/price/prev/change/pct/high/low/qtime
```

- `pct` 单位是**百分数**（`0.48` = +0.48%）；其余数值字段拿不到就给 `None`
- 完整契约、约束与自测步骤见 **`给AI的提示词.md`**（可直接整份发给 AI）；提示词已明确要求
    
  **使用主流的公开免鉴权行情接口**（不需要注册/账号/密钥），并要求自测取到数字才算完成
- 状态栏右端三态：`No source`（没找到文件）/ `Source error`（加载或取数失败，保留上一次数值）/
    
  `HH:MM:SS · 源名字`（正常）
- 运行时是自带的 Python 3.13 embeddable 版：**标准库齐全（含 `ssl` / `urllib` / `http.client`），但没有 pip**，
    
  `provider.py` 只能用标准库
- `provider.path` 可改（默认 `"provider.py"`），`provider.options` 会原样传给 `fetch()`
- **K 线图 / 分时图还需要 `provider.py` 实现 `fetch_kline(code, period, count)` 与
    
  `fetch_minute(code)`** （契约见 `给AI的提示词.md` 第 3.1 节）；没实现时图表窗口会提示缺少函数，
    
  主窗口照常可用

## 界面与操作

- 顶部主页栏显示 `Fear of Missing Out`，可拖动移动窗口；**双击主页栏**折叠 / 展开（折叠后只剩一条，几乎不占地方）
- **拖动窗口四边 / 四角即可自由缩放**（详见下一节）
- 右上角五个小按钮：`＋` 添加 / 删除自选股 · `色` 切换主题 · `顶` 置顶开关 · `藏` 隐藏 · `×` 退出
    
  （打开「外观调节」面板时，这一排会收成单独一个 `✓` 完成按钮，避免误点 `×` 退出）
- 右键任意位置弹出菜单：立即刷新 / 切换主题 / 置顶开关 / 折叠展开 / **名称显示（拼音首字母 ↔ 完整名称）** / **涨跌幅显示模式** / **外观调节（透明度 / 字号）** / **窗口归位** / 添加·删除自选股 / 打开配置文件 / 退出
- 行情行三列：**名称 · 涨跌幅 · 现价**。涨跌幅有**两种显示模式**，右键菜单一键切换：
  | 模式                                                                    | 显示                                                | 配色                                   |
  | --------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------ |
  | **隐蔽模式**（默认）                                                          | 小数 `+0.0081` / `-0.0123`（即 +0.81% / -1.23%，不带百分号） | **不用红绿** —— 上涨是次要灰、下跌是主文字色（浅色主题下接近黑） |
  | **正常模式**                                                              | 百分比 `+0.81%` / `-1.23%`                           | **红涨绿跌**（A 股习惯）                      |
  | 两种模式都走**主题相对色**而不是写死 RGB，深灰主题下才不至于"黑字贴在黑底上"。隐蔽模式适合"在旁边看得见但一眼看不出涨跌"的场景 |                                                   |                                      |
- 左下角的圆点是市场状态灯，旁边是**英文三态**市场状态：
  | 显示        | 含义                             |
  | --------- | ------------------------------ |
  | `Auction` | 集合竞价（9:15–9:30）                |
  | `Trading` | 连续交易（9:30–11:30 / 13:00–15:00） |
  | `Closed`  | 其余所有时段（盘前、午间休市、收盘结算、已收盘、周末）    |
- 已启用单实例保护：重复启动只会唤起已有窗口

## 窗口大小：拖边框自由缩放

把鼠标移到窗口**四边或四角**，指针变成双向箭头后拖动，宽高可任意拉：

- **高度决定整体缩放**：拉高时主页栏、状态栏、行高、字体一起**等比放大**，拉到哪一档都协调；拉窄只影响宽度
- **只拉宽不会锁死高度**：宽度会记住，高度仍保持"按行数自适应"，以后加自选股还会自己往下长
- 最小尺寸 `170×90`（折叠状态 `170×24`），不会缩成一条缝
- **透明主题**下窗口背景是"穿透"的（透明处点不到、鼠标会漏给下面的窗口），所以该主题走 4px 加粗边框——平时只是一道很淡的轮廓，鼠标碰到它就会变清晰，专门用来抓取缩放；右下角另有一个**三角抓手**
- 拖拽结束后新尺寸自动写回 `watch_config.json`（`width` / `height`）；把 `height` 改成 `null` 即恢复"按行数自适应高度"

## 外观调节：三个滑轨（背景透明度 / 字体透明度 / 字号）

**右键菜单 →「外观调节（透明度 / 字号）…」**，窗口会切换成三行滑轨，**拖动即实时生效**：

| 滑轨     | 作用范围                                                                     | 默认 / 范围         |
| ------ | ------------------------------------------------------------------------ | --------------- |
| **背景** | 背景不透明度。普通主题＝整窗半透明（能看到后面的窗口）；透明主题＝菜单栏那层薄纱的浓淡                              | 100% / 10%–100% |
| **字体** | 所有文字的不透明度。普通主题用"字色按比例混向底色"等价实现（底色是实色时与真 alpha 看起来完全一样），透明主题走真正的逐像素 alpha | 100% / 10%–100% |
| **字号** | 字体倍率（`font_scale`），只改字，不改行高与窗口尺寸                                         | 100% / 60%–180% |

- 面板打开时，右上角按钮收成一个 `✓` 完成按钮；**点 `✓`、右键选「完成外观调节」、或双击主页栏**都能退出
- 松开滑轨时数值写回 `watch_config.json`（`bg_opacity` / `font_opacity` / `font_scale`），下次启动保持
- 滑轨的轨道与圆钮**不随"字体透明度"变淡**，所以就算把字体调到 10% 也还能看得到、调得回来
- 面板打开期间**不接受拖动改高**（高度由面板内容决定），关掉面板后恢复原来的高度

## 找不到窗口？（窗口"隐身"的三种自救方式）

本程序是**无任务栏按钮**的置顶小窗，所以要记住这几条：

1. **再双击一次 `启动FOMO.bat`** —— 检测到已有实例时，会把窗口搬回主屏右下角并显示出来（哪怕它已经跑到屏幕外）；
2. 在窗口上**右键 →「窗口归位（移到右下角）」**；
3. 按 `Ctrl+Alt+H` 隐藏 / 显示切换。

另外程序启动时会自检：**上次记住的窗口位置若已不在任何屏幕内，会自动回落到右下角**，不会再出现"启动后看不见"的情况。位置以主屏**工作区**为准（已扣除任务栏），不会压在任务栏下面。

## 自选股配置

**最简便的方式（无需手改文件）**：点右上角 `＋` 按钮，或右键菜单「添加 / 删除自选股…」，在弹出的输入框里直接输入代码即可：

- 添加：用空格或逗号分隔多个代码，例如 `sh000001 sz399001 sz399006`
- 删除：在代码前加 `-` 前缀，例如 `-sz399006`
- 纯 6 位代码会自动识别市场（沪市 6/9 开头 → `sh`，深市 0/2/3 开头 → `sz`）；也可直接带前缀 `sh`/`sz`
- 确认后会弹出提示「新增 X 只，删除 Y 只」
- 输入框由系统 PowerShell 弹窗提供，**启动时已把 PowerShell 那个又大又蓝的控制台窗口彻底隐藏**。隐藏只靠 `CREATE_NO_WINDOW` 一个开关，**不要再叠加 `SW_HIDE`**（原因见 FAQ 14），否则输入框会被一起藏掉
- 弹框是在**后台线程**里等的：输入框开着的时候主窗口照常响应（能拖、能右键、能点 `×` 退出），不会出现"点了没反应 / 程序未响应"
- 弹框期间程序会**临时取消置顶**，避免输入框被置顶的 FOMO 压在下面；关掉程序时若输入框还开着，会一并收掉，不留孤儿窗口

`watch_config.json` 中 `watchlist` 数组，每项 `{"code": "sh000001", "alias": "上证指数"}`：

- `code`：市场前缀 + 6 位代码，深市 `sz`、沪市 `sh`；纯 6 位代码会自动推断（如 `"399001"` → `sz399001`）
- `alias`：显示名，可省略（省略时用行情接口返回的名称）
- 支持 A 股个股与指数：`sh000001` 上证指数、`sz399001` 深证成指、`sz399006` 创业板指等

## 主题与配色

内置 6 套主题（点 `色` 按钮或 `Ctrl+Alt+T` 循环切换）：

| 主题      | 说明                                                                                                                               |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 浅灰白（默认） | 白底浅灰，最素净                                                                                                                         |
| 纯白      | 全白底                                                                                                                              |
| 米白      | 暖白底，护眼向                                                                                                                          |
| 浅蓝      | 极浅蓝灰                                                                                                                             |
| 深灰      | 夜间使用                                                                                                                             |
| **透明**  | **背景完全透明**，桌面壁纸上只浮着一条**半透明薄纱菜单栏**（配深色字）和一行行行情。行情文字为深色、**不加描边**；窗口外圈是一道很淡的轮廓，鼠标移到窗口上时会自动变清晰，方便找到边界和缩放位置。菜单栏是拖动和右键的抓取区；右下角有三角抓手可缩放 |

自定义配色：在配置里加 `custom_theme` 字段（十六进制 RGB），即可多出一套"自定义"主题参与循环：

```json
"custom_theme": {
  "bg": "F7F7F5", "panel": "FFFFFF", "header": "EFEFEA",
  "text": "333330", "sub": "8C8C86", "border": "E4E4DE",
  "up": "C4483F", "down": "2F8F63"
}
```

字段含义：`bg` 窗口底、`panel` 内容面板、`header` 菜单栏、`text` 主文字（**隐蔽模式下也是"下跌"的涨跌幅颜色**）、`sub` 次要文字（**隐蔽模式下也是"上涨"的颜色**）、`border` 分隔线（也是滑轨底色）、`up` 正常模式的**涨色** + 关闭按钮 + 连接失败提示、`down` 正常模式的**跌色**。

还支持几个可选字段，用来微调菜单栏、或做「透明 + 文字描边」的变体：

```json
"custom_theme": {
  "bg": "000000", "panel": "000000", "header": "FFFFFF",
  "header_text": "4E545C", "header_sub": "7C838C",
  "text": "4E545C", "sub": "8A919B", "border": "A8AEB6",
  "up": "D0544B", "down": "3E9C6E",
  "transparent": true,
  "alpha_header": 82, "alpha_border": 45, "alpha_grip": 150
}
```

- `header_text` → 菜单栏标题文字色（**菜单栏是浅色时必须给，否则默认用 `text`，浅底配浅字会看不见**）
- `header_sub` → 菜单栏上那几个小按钮（＋ 色 顶 藏）的颜色
- `transparent: true` → 背景整块透明（`bg` / `panel` 要写 `000000`）
- `alpha_header` / `alpha_border` / `alpha_grip` → 只在透明主题下生效，分别是**菜单栏薄纱、外圈轮廓、右下角抓手**的不透明度（0–255）。想让菜单栏更淡就调小 `alpha_header`；想让外框彻底消失就把 `alpha_border` 设成 `0`
- `shadow: "0B0E13"` → 给所有文字加一圈该颜色的描边（想要"任何壁纸都看得清"就加上它，比如把 `text` 设成 `FFFFFF` 再配深色 `shadow`）

字体大小：`font_scale`（1.0 为默认小字体 9pt / 8pt）。除了改配置，也可以**右键菜单 →「外观调节」用滑轨直接拖**（范围 0.6–1.8）。

## 刷新与延迟

- 交易时段（含 9:15–9:30 集合竞价）默认 **3 秒**一轮；午间 15 秒；休市 30 秒，均在 `refresh_fast / refresh_midday / refresh_slow` 调整
- 行情由 `provider.py` 提供，`fetch()` 每个周期调用一次；程序**不缓存、不重试、不代理**
- 状态栏右侧显示"更新时间 · 数据源名"
- 交易时段若数据超过 2 分钟未更新，状态栏会出现 `· 延迟` 提示
- 节假日不自动识别（休市时数据停更，会显示延迟提示，属正常现象）

## 常见问题

1. **双击 bat 没反应？** 先确认 `python\` 子文件夹和 `fomo.py` 是否都还在（**必须整个文件夹一起用**）。如果只拷了 bat，脚本会去找系统 Python——但**微软商店的 `WindowsApps\python.exe` 是个假货**（点它只会打开商店），本脚本已会自动跳过它，并在都找不到时停下来给你一段安装指引（**不会一闪就没**）。
2. **启动后找不到窗口？** 它没有任务栏按钮。再双击一次 `启动FOMO.bat`，或按 `Ctrl+Alt+H`，或右键选「窗口归位」。
3. **热键没反应？** 检查是否被其他软件占用，可在配置里改组合键；本程序使用系统级 RegisterHotKey，不需要管理员权限。
4. **想开机自启？** 按 `Win+R` 输入 `shell:startup` 回车，把 `启动FOMO.bat` 的快捷方式放进去即可。
5. **想彻底退出？** 点主页栏 `×` 或右键菜单"退出"；按 `Ctrl+Alt+H` 只是隐藏，再按一次恢复。
6. **想看完整股票名？** 右键菜单切「名称显示」，或按 `Ctrl+Alt+N`。
7. **想改窗口大小 / 字体太小？** 直接拖窗口**四边或四角**，整体等比放大（字体也跟着大）。透明主题请拖右下角的三角抓手。
8. **透明主题下点窗口没反应？** 正常现象：背景透明的区域是"穿透"的，鼠标会落到下面的窗口上。要移动窗口请拖**半透明菜单栏**（外圈那 4px 轮廓也可以拉大小），右键菜单也在菜单栏里生效。
9. **透明主题在深色壁纸上文字发飘？** 该主题按需求**不加描边**，走的是浅色路线（半透明薄纱菜单栏 + 深色文字），在浅色壁纸 / 浅色窗口上最清楚。若你常把窗口放在深色壁纸上，可以在配置里加一套"深色 + 描边"的自定义主题（见「主题与配色」，把 `text` 改成 `FFFFFF`、加 `"shadow": "0B0E13"` 即可）。
10. **透明主题的菜单栏/外框还是觉得显眼？** 在 `custom_theme` 里调低 `alpha_header`（菜单栏薄纱）或 `alpha_border`（外圈轮廓，设 `0` 即彻底不要框），数值越小越淡。也可以**右键 →「外观调节」拖"背景"滑轨**直接调。
11. **涨跌幅为什么是 `+0.0081` 这种怪数字？** 这是**隐蔽模式**，把百分比写成小数、并且不用红绿，方便在办公场景下"看得见但一眼看不出涨跌"。想换回 `+0.81%` 红绿显示，右键菜单 →「涨跌幅：正常模式」即可，也可以改配置项 `pct_mode`（`"stealth"` / `"normal"`）。
12. **字体调得太淡，看不见了怎么恢复？** 右键菜单（在主页面栏那一条上点）→「外观调节」，滑轨本身**不会跟着变淡**，拖回 100% 即可；配置项被写坏了也可以直接删掉 `font_opacity` 一行，或在配置里改成 100。
13. **添加自选股时会不会弹黑窗/蓝窗？** 不会。程序已用 `CREATE_NO_WINDOW` 把 PowerShell 的控制台窗口摁掉，只会出现输入框本身。
14. **为什么"隐藏控制台"只要 `CREATE_NO_WINDOW`，不能再加 `SW_HIDE`？** Win32 规定进程**第一次**调用 `ShowWindow` 时会忽略传入的 `nCmdShow`、改用 `STARTUPINFO.wShowWindow`；而输入框恰好就是 PowerShell 进程显示出来的**第一个窗口**，于是跟着一起被强制隐藏 —— 用户点了 `＋` 屏幕上什么都不会出现（叠加 `STARTUPINFO` 的版本就是这么坏掉的）。所以这里只保留 `CREATE_NO_WINDOW`。
15. **点 `＋` 之后能一边等一边用吗？** 能。输入框是在后台线程里等的，主窗口不会被卡住；就算把程序关掉，输入框也会被一并收掉。
16. **双击了启动器，屏幕上还是"什么都没发生"，怎么办？** 现在这种情况理论上不会再有——启动失败的每一层都会主动出声：① 找不到 Python → 控制台停下并给出安装指引；② `fomo.py` 编译不过 → 控制台停下并打出编译错误；③ 程序起来了但初始化失败 → 弹出「FOMO · 启动失败」对话框，里面直接写着原因和日志路径。真遇到"连提示都没有"，请把 `fomo.log` 的最后几行发出来。
17. **日志**：同目录 `fomo.log`，排查问题用，可随时删除。
